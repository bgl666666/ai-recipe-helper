# AI 食谱小助手

输入手头食材，按匹配度推荐家常菜谱，一键生成购物清单。

## 用途

打开冰箱不知道吃什么？把手头的食材输进去，小助手按“已有食材占比”给菜谱打分排序，告诉你每道菜还缺什么，选中菜谱后一键生成购物清单。

## 功能

- 添加 / 删除多项食材，附常用食材快捷按钮
- **本地推荐**：内置 25 道家常菜谱数据库（中式为主，带食材与用量、做法步骤、耗时），本地打分算法按匹配度排序，显示匹配百分比、已有食材 / 缺少食材
- **AI 生成菜谱**：调用 OpenAI 兼容的 chat completions 接口（DeepSeek 等），把食材发给大模型，返回结构化菜谱（菜名、耗时、食材、步骤）；匹配度与已有 / 缺少食材由本应用按同样规则本地计算
- 点菜谱看做法步骤；选入购物清单后汇总缺少食材，可复制
- 没配密钥时只用本地菜谱库，离线可用；配了密钥优先走大模型，调用失败自动回退到本地

## 大模型设置（可选）

打开页面后展开「⚙️ 大模型设置」，填入：

- **API Base URL**：如 `https://api.deepseek.com/v1`（OpenAI 兼容接口地址）
- **API Key**：你自己的密钥
- **模型名**：如 `deepseek-chat`

密钥只保存在本浏览器 localStorage，不会上传到任何服务器，也不会提交到代码仓库。点「清除密钥」可随时删除。

## 怎么跑

不需要构建，不需要安装依赖：

```bash
# 方式一：直接用浏览器打开 index.html
# 方式二：启动一个静态服务（任选其一）
python3 -m http.server 8000
npx serve .
```

然后打开 http://localhost:8000 即可使用。

## 用法

1. 点快捷按钮或输入食材，添加到“我的食材”。
2. 点“本地推荐”用本地菜谱库，或点“AI 生成菜谱”让大模型实时生成（需先在设置里填 API 信息）。
3. 点“看做法”展开步骤；点“选入购物清单”选中想做的菜。
4. 底部购物清单汇总所有缺少的食材，点“复制购物清单”即可带去超市。
